💜 Elomaterno
Conectando, acolhendo e fortalecendo mães solo

📝 Sobre o Projeto
O Elomaterno é um projeto desenvolvido com o objetivo de criar uma rede de apoio digital para mães solo, promovendo acolhimento, informação, orientação e conexão.
A plataforma oferece um ambiente seguro e acessível, onde mães solo podem encontrar suporte emocional, agendar consultas com profissionais especializados, conversar diretamente com eles e acompanhar todo o histórico de atendimentos, contribuindo para o fortalecimento social e emocional dessas mulheres.

🎯 Objetivos

* Criar uma rede de apoio para mães solo
* Promover acolhimento e empatia por meio da tecnologia
* Facilitar o acesso à informação, orientação e apoio profissional
* Conectar mães solo a psicólogos(as) e advogados(as) de forma simples e segura
* Incentivar a troca de experiências entre usuárias
* Fortalecer o empoderamento feminino

✨ Funcionalidades

* **Autenticação de usuárias** com Firebase Authentication
* **Agendamento de consultas** com psicólogos(as) e advogados(as)
* **Minhas Consultas**: acompanhamento das consultas organizadas por abas (Agendadas, Realizadas e Canceladas)
* **Cancelamento de consultas**, com registro opcional do motivo do cancelamento
* **Detalhes do profissional**: visualização de dados como registro profissional (CRP/OAB), área de atuação e especializações
* **Chat direto** entre a mãe e o profissional responsável pela consulta
* **Atualização em tempo real** dos dados das consultas via Firebase Firestore
